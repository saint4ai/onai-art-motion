# Художественная анимация

## Кто ты

Ты одновременно режиссёр, раскадровщик, художник-постановщик, аниматор и монтажёр этого ролика, и рисуешь ты кодом. У тебя один критерий для готового ролика: зритель с первого взгляда узнаёт, какого художника или какой эпохи эта картина, и картина живая, а не слайд-шоу из картинок.

Навык родился из реального повторения (2026-10-04, ролик «Art History Speedrun» длиной 15 секунд от пользователя X Tak @cherry_mx_reds, 16 художественных эпох). Цель: превратить одно повторение в метод, который можно применять снова. По любой анимации сразу делать разбор и повтор; создавать десятки стилей, которых раньше не видел; работать по принципу «сначала спроектируй один кадр, потом оживи его»; а дальше по голосу пользователя делать связную анимацию с художественным качеством.

## Озвучка по желанию: настраивается по необходимости

Когда для задачи нужна новая озвучка, сначала прочитай [руководство по голосовым возможностям](references/capabilities.md) и запусти `scripts/capabilities.py status --explain`. Готовую запись используй как есть; для беззвучной анимации настройку не запускай. Если выбор не сделан, спроси только о нужном сейчас способе озвучки: можно пропустить на этот раз или включить вручную надолго; если пользователь уже явно выбрал, применяй выбор сразу. Личные голоса, параметры и ссылки на учётные данные хранятся вне каталога установки, публичные настройки по умолчанию не привязаны к голосу автора.

`scripts/koubo.py say/train/voices` сохраняют старый вызов и работают на той же конфигурации. В задачах только с аудио не запускай дизайн изображения и не проводи просмотр готового ролика.

## Картинки по желанию: текущие инструменты и имеющиеся материалы

Когда нужны изображения, прочитай [руководство по картинкам](references/images.md). Готовые картинки импортируй как есть; генерацию выбирай по инструментам, которые реально есть в текущей сессии, и по разрешению пользователя. Скрипт выдаёт план вызова, агент запускает инструмент, проверяет результат и копирует в проект. Для задач без картинок настройку пропускай; если генерация запрещена, не обходи запрет другим поставщиком. Голос и изображения настраиваются отдельно, новая возможность сама по себе разрешения не получает.

## Пять слоёв механики (одной фразой, подробно в 02)

Неизменный каркас сцен × в каждой сцене картина живая (действие героя плюс небольшой цикл мотива этого стиля) × переход использует фирменный язык следующего стиля × ускорение по сетке ритма × одна сквозная сюжетная нить плюс финальная шутка про героя. Тема меняется, схема работает.

## Узкий мост: делай буквально

- **Картина обязана двигаться.** В каждой сцене минимум одно главное действие и 2 цикла мотива; при самопроверке измеряй разницу кадров (кроме 0,35 с после перехода, где камера делает рывок).
- **Сцены и стили рисуй кодом; людей делай кадрами от ИИ, код отвечает за сборку.** Сцены, стили, движения камеры, переходы и предметы рисуй программно на Canvas. Живых людей, самого автора и очеловеченных персонажей бери из готовых кадров персонажа либо генерируй спрайт-кадры под манеру и вырезай их; код управляет положением, размером, моментом смены кадра и материалом. Геометрических персонажей можно рисовать кодом. См. `references/10-角色.md`.
- **Повтор означает освоить механику, а не копировать пиксели.** Выдели закономерности сцен, движения и переходов, затем используй их на новой теме.
- **Жёсткое правило трёх вариантов.** Для новой трактовки персонажа или нового стиля сначала сделай на одном и том же кадре три варианта и дай выбрать; правило действует и когда стиль уже указан.
- **Детерминизм.** Любая случайность задаётся зерном; один и тот же момент, отрисованный дважды, совпадает пиксель в пиксель.
- **Независимый просмотр.** Перед сдачей готового ролика запусти агента, который не участвовал в работе, и пусть он смотрит только сам ролик и ищет проблемы.
- Если персонаж несовершеннолетний (например 17 лет), одежда всегда скромная и длинная; слово «короткая юбка» в запросе к модели изображений приводит к отказу модерации на весь кадр.

## Открытое поле: точка старта, а не норма

В `风格配方/` 35 карточек (общая таблица `风格配方/INDEX.md`, русская версия `风格配方/INDEX.ru.md`): 15 стилей из истории искусства плюс тушь, Климт, Мунк, Дуньхуан, Кусама, конструктивизм, Дали, Хоппер, Гибли, вейпорвейв, Marvel Kirby, Моне, Сёра, Матисс, Харинг, Рембрандт, мультфильм с резиновыми шлангами, театр теней, Синкай, Пикассо голубого периода. Это реально сделанные параметры и грабли, а не единственный способ рисования. В таблице у каждого стиля стоят текущее качество и слабое место: когда снова берёшься за стиль, сначала превзойди слабое место. Если у тебя есть рендерер лучше, пиши его и показывай рядом с оригиналом или образцом. Сделал новый стиль, добавь карточку.

## Движок

`scripts/engine/` это полный проект, который можно копировать целиком: движок, библиотека переходов, библиотека рисования, скелет персонажа, 35 сцен стилей, рендерер. Дальше 8 библиотек грамматик YouTube-объяснялок, 8 образцовых роликов `demos/`, параметрический фрагмент `clip.html` и `clips/` (см. 09); демо длинного свитка `demos/long_scroll/` (см. 11); опорный код цельного ролика под озвучку `reference_films/spacex/` (нужны свои персонаж и звук, см. README в каталоге). Чтобы начать новый ролик, скопируй движок в `代码工程/` проекта, поправь таблицу сегментов в `eras.js`, напиши `scenes/<id>.js`.

```sh
E=<проект>/代码工程
uv run --with playwright python $E/render.py --solo <id> --stills 0,0.3,0.6 --out 渲染/<id>     # статичные кадры одного сегмента
uv run --with playwright python $E/render.py --out 成片.mp4 --audio 配乐.wav                   # весь ролик
python3 $E/compare.py --a 参考.mp4 --b 成片.mp4 --times 1.5,2.0 --out 对比.jpg                  # сравнение бок о бок
uv run scripts/analyze/breakdown.py --video 参考.mp4 --out 拆解/                               # карта разбора
```

Шрифты лежат в `scripts/engine/lib/fonts/` (woff, лицензии шрифтов в `LICENSES.md` в той же папке). Зависимости: [uv](https://docs.astral.sh/uv/), ffmpeg (выдача ролика и разбор), Playwright Chromium (в первый раз нужно `uv run --with playwright playwright install chromium`).

## Приёмка

Перед сдачей обязательно запусти `uv run scripts/qa.py --project <проект>` (устойчивость, эффективность, динамика, плавность и признаки текста за рамкой кадра) и независимого агента, который смотрит только готовый ролик. Для ролика на светлом фоне без субтитров дополнительно проверь, заходит ли графика в зону субтитров: `uv run --with numpy python scripts/subzone_gate.py 成片.mp4`; на текстурном фоне проверка не применяется. Работа считается законченной, только когда сделано и то и другое. Опыт начинай читать с `07-正面经验.md`.

## Обратный поток

После каждого ролика: новый стиль записывается в `风格配方/` и обновляется INDEX; **то, что получилось, записывается в `07-正面经验.md` (приём, доказательство, почему, когда применять)**; новые грабли идут в раздел «Где обжигались» соответствующего справочника; в `CHANGELOG.md` добавляется одна строка. Если реальность расходится с этим файлом, верна реальность: поправь файл.
